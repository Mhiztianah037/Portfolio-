# Olanrewaju Funmilola — Portfolio

This folder contains the updated multi-page portfolio website, based on the HTML/CSS files supplied in the chat. The selected second professional portrait has been integrated into the homepage profile card and About page.

## Files
- `index.html` — homepage
- `about.html` — biography and skills
- `education.html` — education page
- `contact.html` — contact page
- `style.css` — responsive styles (based on the supplied `style_2.css`)
- `script.js` — mobile navigation and current-year footer
- `assets/funmilola-professional-portrait.png` — selected professional portrait
- `logo.svg` — supplied logo

## Preview
Open `index.html` in a browser, or run `python -m http.server 8000` in this directory and visit `http://localhost:8000`. Keep the `assets` folder beside the HTML files when uploading.

## Before publishing
Replace remaining sample contact details (email, phone and GitHub URL) and confirm school/course information. The contact form currently uses a `mailto:` action and opens the visitor’s configured email application; it is not a server-backed form.
